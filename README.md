# MOVE ON · Daily Fitness Check-in

A lightweight, privacy-first fitness habit product built through vibe coding.

## 在线体验 · Live Demo

**[打开 MOVE ON](https://echohux.github.io/move-on-daily-fit/)**

No account is required. Fitness data stays in the current browser.

## Product problem

Fitness plans often fail because starting is difficult and progress is invisible. MOVE ON reduces the first-step cost with a no-login flow, a clear daily plan and immediate progress feedback.

## Product highlights

- Personalized plans based on goals, experience and equipment
- Daily exercise list and completion progress
- One-tap check-in, streaks and total training time
- Yearly activity calendar with up to 365 days of history
- Responsive mobile and desktop experience

## Product decisions

- **No registration before value:** users can start immediately.
- **Visible habit loop:** daily completion and streaks reinforce continuity.
- **Local-first privacy:** body profile and training history stay in the browser.
- **Clear safety boundary:** fitness guidance does not replace medical advice.

## Privacy

- No real email, account, API key, database credential or hosting project ID is included.
- Environment files, hosting metadata, build output and local caches are excluded.
- Profile and check-in data remain in the current browser.
- Clearing browser storage also removes the data.
